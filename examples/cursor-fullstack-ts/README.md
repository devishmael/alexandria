# Cursor Fullstack TypeScript Starter

Minimal starter project demonstrating zero-config Alexandria governance in Cursor.

## Included Files
- `.cursorrules`: Instructs Cursor to enforce Fact-Forcing (`E_FACT_FORCING`) and strict TDD.
- `mcp.json`: Connects Cursor to local `alexandria mcp` server.
- `package.json`: TypeScript + Vitest setup.
